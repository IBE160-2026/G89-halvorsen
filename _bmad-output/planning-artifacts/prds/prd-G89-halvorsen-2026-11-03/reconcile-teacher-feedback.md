## Genuine carry-forward gaps

### G1 — Development process and AI-steering evidence

The feedback explicitly values the traceable BMAD-to-code chain and suggests retaining prompt iterations for generation and references. Stable FR IDs, the PRD decision log and test evidence do not by themselves capture implementation-time prompts, AI steering, code review/quality assurance and the mapping to later stories and code. Preserve this as a downstream delivery/reflection obligation with an owner and revisit point; it does not belong in the student-facing product flow and is not a demand for implementation evidence now.

### G2 — Architecture and README/repository handoff

FR-42 covers the key-free demonstration, but PRD/addendum do not explicitly preserve the full teacher-requested setup handoff: a simple justified stack, rationale for the model and PDF library, provider cost/setup considerations, runnable local README and a safe configuration example such as `.env.example`. These are Architecture/README/repository deliverables, not new FRs or selected technologies. Permissioned demo materials and credential protection are already covered.

### G3 — UX sketches and deliberate design validation

The flow is specified in enough detail to sketch, but the teacher's suggested source-reference and wrong-answer-flow sketches and the expectation of a deliberate design are not recorded as an owned downstream UX activity. Preserve that expectation as a proportionate handoff using the existing UJ-1 and FRs; no new screen, feature or completed usability test is implied.

## Not counted as missing PRD requirements

- Actual PDFs, measurements, app tests, final numerical implementation bounds and provider verification are openly pending at the appropriate stage.
- Historical feedback on the older brief does not override the user's subsequent quiz simplification, temporary sessions, stronger source-validation policy or cross-discipline scope.
- Suggested phase-2 storage, a particular implementation order, extra project difficulty and a separate long-explanation mode have not been silently adopted.
- The original assignment, complete grading rubric and exact deadline still need confirmation before final delivery planning, as already tracked in the PRD.
