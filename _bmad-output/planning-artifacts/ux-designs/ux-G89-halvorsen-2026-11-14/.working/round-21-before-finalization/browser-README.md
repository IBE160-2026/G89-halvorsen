# AI Study Buddy — browser concept preview

From the project root, run:

```sh
python3 _bmad-output/planning-artifacts/ux-designs/ux-G89-halvorsen-2026-11-14/.working/browser-preview/serve_preview.py
```

Open the local URL printed by the server. It normally uses `http://127.0.0.1:8765/`; if that port is occupied, it selects another free local port. Stop it with Ctrl+C.

The single menu inside the app exposes Home, Summary, Flashcards and Quiz using saved example content. Together these screens are the selected concept; minor refinements remain possible and UX is still in progress. The main preview opens the illustrated empty Home and permits learning-tab inspection of labelled examples before the first startup/reset. With an active example or metadata-only session, Home shows filename, locked output language/Summary detail, and the approved equal-sized Continue studying and New session actions. Continue returns to the last visited learning tab, initially Summary if none has been visited, preserving content/progress. Returning to Flashcards shows the front of the retained card; Quiz answers/feedback remain intact.

New session is directly visible on active Home and beside the document information on learning screens. The existing dialog preserves all session state on Cancel/Escape and returns focus to its invoking button. Confirmation clears the working session to empty Home and disables learning links until fresh PDF/settings/acknowledgement startup; the original local file is unaffected and the student may stop there. PDF selection is metadata-only; no PDF text or AI service is used. Real processing, cleanup and late-result rules remain governed by the PRD.
