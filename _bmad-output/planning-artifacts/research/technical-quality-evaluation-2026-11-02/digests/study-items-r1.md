## Practical evaluation proposal — decisions, not reported findings

Each proposal inherits source metadata above. Confidence here concerns reasonableness of the proposed evaluation approach; no universal pass threshold is implied.

| Proposal | Source / class / confidence | Caveat |
|---|---|---|
| P1. For MCQs, record separate judgments for key correctness, competing answers, stem clarity, distractor plausibility and clueing; ask a second reviewer to adjudicate disagreements. | S1; applied inference; moderate | Transfer outside health sciences needs local review. |
| P2. For flashcards, review whether the front asks a bounded recall question and the back supplies a correct, checkable answer; hide the back until an attempt. Treat one correct attempt as practice progress. | S2/S4; design inference; moderate | Neither experiment validates a universal flashcard-writing rubric or an atomic-card size rule. |
| P3. For both formats, retain the PDF page/span supporting each answer and feedback explanation; manually compare meaning, qualifiers, numbers and terminology with that passage. Flag unsupported material. | S1/S3; engineering safeguard proposed here; moderate | Source anchoring is our auditability choice, not a procedure tested in these studies. A citation alone does not prove entailment. |
| P4. Review English and Bokmål separately using competent readers. Check negation, technical terms, qualifiers and whether translation introduces another correct option; use paired source passages where possible. | S1; contextual inference; moderate | No English–Bokmål equivalence study or language-specific validated rubric was found in this bounded review. |
| P5. Use a deliberately small, documented review set spanning language, topic and PDF characteristics; record item-level judgments and denominators, reviewer disagreements and unresolved defects. Declare sample size and release policy as project decisions before the review. | S1; evaluation-design proposal; moderate | Not a representative population estimate; no defensible universal sample size or pass percentage was established. |
| P6. Show corrective feedback after answering, identify the correct answer and verify its explanation against the PDF. If later assessing learning, use a delayed test and an explicit comparison condition. | S2/S3; applied inference; moderate | Merely checking output quality or user satisfaction cannot demonstrate improved retention. No effect size for the app is available. |

## What remains unknown and stopping reason

No app outputs were generated or scored; there are no claimed app test outcomes. The reviewed sources do not establish a universal acceptance percentage, optimal count of flashcards per page, ideal card length, optimal distractor count, best spaced-repetition algorithm, automated judge accuracy, English–Bokmål parity, or educational effectiveness of AI-generated study material. These are gaps in this bounded review, not claims that no research exists.

Stop: the requested structural MCQ guidance, retrieval rationale, feedback evidence and flashcard-adjacent experiment were covered within four primary works and five web calls. The only targeted follow-up filled the flashcard-specific retrieval gap. Further broad searching would exceed the intended compact first round; app-specific effectiveness requires new evaluation evidence rather than more confident extrapolation.
